Rätsel bauen

Wähle zuerst das Nabelwort — das Wort, das in alle vier Kategorien passt. Dann je zwei weitere Wörter pro Kategorie. Jedes dieser Wörter darf nur in seine eigene Kategorie passen, sonst hat das Rätsel mehr als eine Lösung.

Vorschau

Der Code kommt ans Ende der Liste in puzzles.js — die id ist schon hochgezählt. Danach tests/run.sh laufen lassen; die Datenprüfung dort fängt dieselben Fehler wie die Vorschau oben.
